Der Unterschied zwischen einem Pianisten, der Fortschritte macht, und einem, der stecken bleibt, kommt oft auf eines hinaus: Absichtlichkeit. Dieselben Dinge jeden Tag auf dieselbe Weise zu üben fühlt sich produktiv an, ist es aber oft nicht. Ein Übetagebuch verwandelt ziellose Wiederholung in fokussierten, messbaren Fortschritt.
Dieser Leitfaden behandelt, warum Tagebuchschreiben funktioniert, was zu verfolgen, eine Vorlage, die Sie heute nutzen können, und wie man Tagebuchschreiben zu einer Gewohnheit macht, die haftet.
## Warum ein Übetagebuch führen?
- **Macht Üben absichtlich** — Sie entscheiden, woran Sie arbeiten, bevor Sie sich hinsetzen, statt zu spielen, was sich bequem anfühlt
- **Verfolgt Fortschritt über Zeit** — Sie können Verbesserung sehen, die Tag für Tag unsichtbar ist
- **Identifiziert Muster** — Sie bemerken, welche Stücke stagnieren, welche Techniken mehr Aufmerksamkeit brauchen, zu welchen Tageszeiten Sie am besten üben
- **Baut Motivation auf** — Eine Serie von Übetagen und eine wachsende [Repertoire](/blog/how-to-build-piano-finger-independence)-Liste zu sehen ist zutiefst befriedigend
- **Verbessert Problemlösung** — Ein Problem aufzuschreiben zwingt Sie, es zu artikulieren, was oft die Lösung offenbart
<Callout type="note">
Ein Übetagebuch ist kein Tagebuch. Sie schreiben nicht über Ihre Gefühle (obwohl Sie können). Sie verfolgen, was Sie taten, was funktionierte, was nicht und was als Nächstes zu tun ist. Es ist ein Trainingslog für einen Musiker-Athleten.
</Callout>
## Was zu verfolgen
### Wesentliche Felder
- **Datum** — Wann haben Sie geübt?
- **Dauer** — Wie lange haben Sie geübt?
- **Repertoire** — An welchen Stücken haben Sie gearbeitet?
- **Spezifischer Fokus** — Welchen Abschnitt, welche Technik oder welches Problem haben Sie angegangen?
- **Tempo** — In welchem Tempo haben Sie gearbeitet? (BPM von Ihrem Metronom)
- **Was gut lief** — Was verbesserte sich oder fühlte sich gut an?
- **Was Arbeit braucht** — Was war schwierig oder verbesserte sich nicht?
- **Plan für nächste Sitzung** — Worauf sollten Sie sich beim nächsten Mal konzentrieren?
### Optionale Felder
- **Aufwärmen** — Welche Aufwärmübungen haben Sie gemacht?
- **Tonleitern/Arpeggien** — Welche Tonarten haben Sie geübt?
- **Stimmung/Energie** — Waren Sie fokussiert, müde, energetisiert?
- **Durchbrüche** — Hat heute etwas geklickt?
- **[Fragen](/blog/how-to-choose-a-piano-teacher) an den Lehrer** — Dinge, die Sie in der nächsten Lektion fragen wollen
## Die Vorlage
Hier ist eine einfache Vorlage, die Sie in ein Notizbuch, eine Tabelle oder eine Notizen-App kopieren können (die Trennlinien markieren Anfang und Ende der Vorlage):
***
**Datum:** _______________  **Dauer:** _______ Min
**Aufwärmen:**
- [ ] Tonleitern: _______________
- [ ] Arpeggien: _______________
- [ ] Andere: _______________
**Repertoire:**
| Stück | Abschnitt | Fokus | Tempo (BPM) | Notizen |
|---|---|---|---|---|
| | | | | |
| | | | | |
| | | | | |
**Was gut lief:**
_________________________________________
**Was Arbeit braucht:**
_________________________________________
**Plan für nächste Sitzung:**
_________________________________________
***
<Callout type="tip">
Halten Sie es einfach. Wenn Ihr Tagebuch mehr als 2-3 Minuten zum Ausfüllen braucht, werden Sie es nicht tun. Das Ziel ist Konsistenz, nicht Vollständigkeit. Ein Ein-Zeilen-Eintrag („20 Min geübt, an Mondscheinsonate 3. Satz gearbeitet, Tempo 60 BPM, Linkshand-Arpeggien noch ungleichmäßig") ist besser als gar kein Eintrag.
</Callout>
## Wie man das Tagebuch wirksam nutzt
### 1. Vor dem Üben planen
Bevor Sie sich ans Klavier setzen, schauen Sie Ihren letzten Tagebucheintrag an. Was haben Sie gesagt, woran Sie arbeiten würden? Starten Sie dort. Das verhindert die [häufige](/blog/how-to-learn-piano-as-an-adult) Falle des „Übens" durch Durchspielen von Stücken, die Sie schon kennen.
### 2. Spezifisch sein
Schreiben Sie nicht „Mondscheinsonate geübt". Schreiben Sie „Takte 32-48 des ersten Satzes geübt, Hände einzeln, bei 50 BPM. Linkshand-Arpeggien in Takt 40 noch ungleichmäßig."
Spezifität hilft Ihnen:
- Dort weiterzumachen, wo Sie aufgehört haben
- Zu verfolgen, ob ein spezifisches Problem sich verbessert
- Ihrem Lehrer genau zu zeigen, woran Sie gearbeitet haben
### 3. Tempo verfolgen
Notieren Sie immer Ihr Metronomtempo. Das ist das objektivste Maß für Fortschritt. Wenn Sie letzte Woche an einer Passage bei 60 BPM arbeiteten und diese Woche bei 72 BPM, haben Sie sich verbessert — selbst wenn es sich nicht so anfühlt.
### 4. Wöchentlich überprüfen
Einmal pro Woche schauen Sie Ihr Tagebuch durch. Fragen Sie:
- [ ] Habe ich so viele Tage geübt, wie ich geplant hatte?
- [ ] Welche Stücke schreiten voran? Welche stecken fest?
- [ ] Verbringe ich zu viel Zeit mit einem Stück und vernachlässige andere?
- [ ] Gibt es Muster — kämpfe ich immer am selben Tag oder zur selben Zeit?
- [ ] Worauf sollte ich mich nächste Woche konzentrieren?
### 5. In Lektionen nutzen
Wenn Sie einen Lehrer haben, bringen Sie Ihr Tagebuch zu Lektionen. Es hilft Ihrem Lehrer zu sehen, woran Sie gearbeitet haben, wie viel Sie geübt haben und wo Sie stecken. Es zeigt Ihrem Lehrer auch, dass Sie ernst über Ihren Fortschritt sind.
## Digital vs. Papier
### Papiertagebuch
**Pro:** Keine Bildschirmablenkung, taktil, fühlt sich persönlich an, kann Diagramme zeichnen
**Con:** Nicht durchsuchbar, nicht sicherbar, kann keine Statistiken erzeugen
### Digital (Notizen-App, Tabelle, Notion)
**Pro:** Durchsuchbar, sicherbar, kann Statistiken verfolgen, überall zugänglich
**Con:** Bildschirmversuchung, weniger taktil, fühlt sich vielleicht weniger persönlich an
<Callout type="note">
Es gibt keine richtige Antwort. Das beste Tagebuch ist das, das Sie tatsächlich nutzen. Wenn Sie Notizbücher lieben, nutzen Sie Papier. Wenn Sie immer am Telefon sind, nutzen Sie eine Notizen-App. Das Format [zählt](/blog/how-to-memorize-piano-pieces-faster) weniger als die Gewohnheit.
</Callout>
## Es zur Gewohnheit machen
- **Am Klavier aufbewahren** — Das Tagebuch sollte sichtbar sein, wenn Sie sich zum Üben hinsetzen
- **Sofort ausfüllen** — Schreiben Sie Ihren Eintrag direkt nach dem Üben, während es frisch ist
- **Klein anfangen** — Verpflichten Sie sich zu einer Zeile pro Sitzung. Sie können immer mehr schreiben.
- **Die Kette nicht brechen** — Markieren Sie jeden Tag, an dem Sie üben, auf einem Kalender. Die visuelle Serie ist motivierend.
- **Ehrlich sein** — Blähen Sie Ihre Übungszeit nicht auf oder tun Sie nicht so, als sei eine Sitzung besser gelaufen, als sie war. Das Tagebuch ist für Sie, nicht zur Schau.
## Eine Beispielwoche
| Tag | Dauer | Fokus | Tempo | Notizen |
|---|---|---|---|---|
| Mo | 30 Min | Bach Invention 1, T. 1-8 | 60 BPM | Hände einzeln, RH sauber, LH braucht Arbeit |
| Di | 25 Min | Bach Invention 1, T. 1-8 | 65 BPM | Hände zusammen langsam, T. 5-6 noch rau |
| Mi | 30 Min | Bach Invention 1, T. 1-12 | 55 BPM | Bis T. 12 erweitert, langsameres Tempo für Genauigkeit |
| Do | — | — | — | Kein Üben (Reise) |
| Fr | 40 Min | Bach Invention 1, T. 1-12 | 62 BPM | Viel besser! T. 5-6 heute geklickt |
| Sa | 45 Min | Bach Invention 1, ganzes Stück | 50 BPM | Ganzes Stück durchgespielt, rau aber komplett |
| So | 20 Min | Wiederholung + Blattspiel | — | 3 kurze Stücke blattgespielt, Spaß |
Nach einer Woche Tagebuchschreiben können Sie genau sehen, woran Sie gearbeitet haben, wie es voranschritt und worauf Sie sich als Nächstes konzentrieren. Diese Sichtbarkeit ist Macht.
